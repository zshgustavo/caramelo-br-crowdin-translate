# Caramelo BR Translators 🇧🇷

Community-driven English → Brazilian Portuguese translation project managed through [Crowdin](https://br.crowdin.com/project/caramelo-br-translators).

The goal of this project is to help translate English words, terms, and strings into clear, natural, and consistent Brazilian Portuguese (`pt-BR`).

## 🌎 Translation Project

## 🤝 How to contribute

No local development environment is required. Contributions are made directly through Crowdin.

1. Open the [Caramelo BR Translators project on Crowdin](https://br.crowdin.com/project/caramelo-br-translators).
2. Sign in or create a Crowdin account.
3. Select the available translation file or section.
4. Choose an untranslated English word or string.
5. Add the corresponding translation in Brazilian Portuguese.
6. Review the context, spelling, punctuation, and terminology before submitting.

## ✍️ Translation guidelines

Translations should prioritize meaning and natural Brazilian Portuguese rather than literal word-for-word conversion.

- Use **Brazilian Portuguese (`pt-BR`)** spelling and vocabulary.
- Preserve the original meaning and intent.
- Prefer terminology commonly used in Brazil.
- Keep technical terms in English when they are conventionally used that way in Portuguese.
- Preserve placeholders, variables, tags, Markdown, HTML, or formatting tokens exactly when present.
- Do not translate proper names, product names, commands, API names, or code identifiers unless the context explicitly requires it.
- Keep capitalization and punctuation consistent with the source when appropriate.
- Avoid unnecessarily formal or machine-translated wording.
- Check existing translations before introducing a new term so the vocabulary remains consistent across the project.

## ✅ Before submitting a translation

Check that:

- the translation sounds natural to a Brazilian Portuguese speaker;
- accents and spelling are correct;
- the original meaning has been preserved;
- placeholders and formatting have not been changed;
- terminology is consistent with other translations;
- the translation does not add information that is absent from the English source.

## 🔍 Review process

Translations may be reviewed, discussed, corrected, or improved by other contributors before being considered final. Suggestions and alternative translations are welcome when they improve clarity, accuracy, or consistency.

When a term is ambiguous, prefer discussing it in Crowdin rather than guessing.

## 💬 Community

This is a collaborative translation project. Constructive suggestions, terminology discussions, and proofreading contributions are encouraged.

Whether contributing one word or hundreds, every reviewed translation helps improve the quality of the Portuguese version.
